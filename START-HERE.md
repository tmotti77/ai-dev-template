# 🚀 START HERE - Quick Reference

## For New Projects (Every Time)

```powershell
# 1. Clone template
git clone https://github.com/tmotti77/ai-dev-template.git my-new-project
cd my-new-project

# 2. Run setup (installs MCP server)
.\setup.ps1

# Done! ✅
```

The setup script will ask if you want to:
- Open Cursor → Say **yes**
- Launch terminals → Say **yes**

---

## What Opens Automatically?

### ✅ Auto (via setup.ps1)
- Cursor editor (if you say yes)
- 4 AI terminals (if you say yes)

### ⚠️ Manual (First Time Only - 5 min)
- Configure agents in Cursor's Agent panel
- See **NEW-PROJECT-SETUP.md** Step 4

### ✅ Auto (After First Time)
- Agents already configured in Cursor
- Just use them!

---

## Daily Workflow

```powershell
# Morning
cd my-project
cursor .                    # Open Cursor
.\launch-terminals.ps1      # Open AI terminals

# Work with agents in Cursor
# Switch between Claude, Grok, Gemini, Codex, Copilot

# Evening
git add .
git commit -m "Your work"
git push
```
